# S7.1 follow-up — Node 24 action runtimes

## Findings

The release-build Windows job in run 37250231276 warns that `actions/upload-artifact@v5` and `ilammy/msvc-dev-cmd@v1` target Node 20 and are forced to run on Node 24. The collection job also uses `actions/download-artifact@v5`, whose metadata declares Node 20. The requested replacement runtime is Node 24. [GitHub deprecation notice](https://github.blog/changelog/2025-09-19-deprecation-of-node-20-on-github-actions-runners/).

The official upload v7 and download v8 actions declare Node 24; their existing archive defaults support these workflows' named, zipped artifacts. Checkout v5, setup-python v6 and rust-cache v2 already declare Node 24. [Upload metadata](https://github.com/actions/upload-artifact/blob/v7/action.yml), [download metadata](https://github.com/actions/download-artifact/blob/v8/action.yml).

MSVC setup is used after the Rust builds solely to locate `dumpbin` for static CRT inspection. A small PowerShell helper locates the existing Visual Studio installation using Microsoft's `vswhere` and adds the native x64 tool directory to the job path. Missing tools and failed inspection must fail the job. This removes the outdated JavaScript action without installing tools or suppressing warnings. [Microsoft discovery guidance](https://github.com/microsoft/vswhere/wiki/Find-VC).

These dependencies run in CI; the shipped Pumice executable does not gain a Node runtime dependency. Native Windows behavior is verified by CI; Linux workflow validation cannot execute the Visual Studio tool.

## Questions for the owner

None. This is maintenance of the approved S7.1 build and artifact pipeline, with no release publication, product behavior or Windows-side installation.
