# S7.1 — release build archives

## Findings

The owner authorized starting Phase 3 on 2026-10-04, after merging the remaining passthrough PR (#32). Initial distribution work produces GitHub Actions archives, without creating a release/tag or changing Cargo's version.

Four explicit targets cover Windows x64, portable Linux x64, and both Apple Silicon and Intel macOS. GitHub's current native macOS labels distinguish `macos-15` (arm64) from `macos-15-intel` (x64); one `macos-latest` row is insufficient to establish both architectures. See the [official runner reference](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).

The Linux archive uses `x86_64-unknown-linux-musl`, whose C runtime is statically linked by default according to the [Rust linkage reference](https://doc.rust-lang.org/reference/linkage.html#static-and-dynamic-c-runtimes). Inspect the binary's ELF program/dynamic headers before making the standalone claim. Windows retains `+crt-static` and dependency inspection. Native test runs use fake CLIs only.

The package contains the product executable, license and example YAML. Archive extraction and version/config-validation smoke checks exercise the packaged file, not only the build-tree executable. Checksums detect archive corruption; the initial artifacts are unsigned and macOS notarization is not claimed.

The next independent story is S7.5: generated Keep a Changelog release notes from Conventional Commits, SemVer/package matching and release preparation. Public publication and signing remain separate owner-controlled steps. Startup and installer/update work follow, with the installation guide completed once their behavior is settled.

## Questions for the owner

- **Startup:** sign-in under the owner's account versus a pre-login service is still open. Background jobs do not necessarily inherit an interactive shell's PATH or CLI login. Native Windows installation also does not reuse WSL CLI credentials. Unix startup needs tested SIGTERM shutdown before its gate is passed.
- **Installer:** [S0.4's owner decision](S0.4-stack.md#owner-decisions-2026-10-04) postponed Tauri versus a plain installer to this phase. The spec's Tauri proposal and the WebView2/no-runtime-dependencies question remain to be resolved; S7.1 does not select a framework.
- **Updates:** the AGENTS.md outbound-call rule needs an explicitly approved exception for official GitHub release checks/downloads before adding network update code. No updater is part of S7.1.
- **Release readiness:** first public version and signing/notarization credentials are owner-controlled. This story does not create a tag, publish a release or read signing credentials.
