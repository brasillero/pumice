# P15 design (Codex, 2026-10-18, read-only at de0885f) — condensed by the orchestrator

- **OpenAI contract** (official reference): multipart `file`, `model`; optional `language` (input language), `prompt`, `temperature` 0–1, `response_format` json|text|srt|verbose_json|vtt|diarized_json, `stream`, timestamps, `include[]`, `chunking_strategy` and newer fields. `json` = object with `text`; `text` = plain body. Errors: `{"error":{"message","type","param","code"}}` with non-2xx status. `/v1/models`: `{object:"list",data:[{id,object:"model",created,owned_by}]}`.
- **Clients:** Handy transcribes locally and only uses chat + models. OpenWhispr supports a custom transcription endpoint (file, model, language, optional prompt; reads `text`; no explicit timeout). T3 Code upstream (9c16146) has no configurable OpenAI transcription endpoint; environment-backed transcription is documented as unimplemented.
- **Models = flows.** Model id = flow id. New `serve.transcription_flows` publication list (default empty). Public id charset `[A-Za-z0-9][A-Za-z0-9._-]{0,127}`. "Off" = `formatter: null` + `relay_route: passthrough`. One warm audio model: every published flow must use `serve.transcription_model`. Located validation errors.
- **Execution:** reuse Operation/Runtime/PreparedFlow/WarmTranscriber and the dictation admission/cancellation/cleanup machinery; one permit shared by both endpoints (busy 429 `rate_limit_exceeded`, `Retry-After: 1`). Forward `language`, `prompt`, `temperature` to the transcription child only (warm transport gets per-request options). `response_format` json|text; reject the rest and `stream=true`.
- **Response:** `{"text": final, "pumice": {schema_version, transcript{text,language,audio_seconds}, post_processing{status: off|applied|skipped|failed, …}, stages, timings_ms}}`; text format: exact text + `Pumice-Postprocessing-Status` header.
- **D4:** post-processing failure → 200, raw transcript as `text`, status `failed` with safe details. Transcription/request failure → OpenAI error envelope (400/403/404 model_not_found/405/408/413/429/500/502/503/504). Same limits and privacy rules as dictations.
- **/v1/models:** published flows only, optional `pumice` object per entry (flow, transcription_model, preset, relay_route, response_formats, ready, budgets); listed with `ready:false` while restarting; no network work.
- **Test page:** embed the existing `tools/transcribe-test` page logic in `pumice`, serve at `GET /`, same-origin `/v1`, CSP, guard; owner reaches it with an SSH local forward on the same port (Host check).
- **No `/v1/chat/completions` now.**
- **Split:** P15.1 config + registry + models (350–600 lines); P15.2 endpoint + D4 (900–1500); P15.3 test page (250–500).
